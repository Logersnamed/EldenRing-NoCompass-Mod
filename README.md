# EldenRing NoCompass Mod
A [mod](https://www.nexusmods.com/eldenring/mods/8929) that hides annoying compass in Elden Ring single-player. It completely removes the compass HUD element regardless of your in-game HUD settings. 

> [!IMPORTANT]
> Other DLL mod loaders should also work, but so far I’ve only tested [EldenModLoader](https://www.nexusmods.com/eldenring/mods/117).  
> It should work on **Linux**, but I haven’t tested it myself.

## Installation
1. Disable anti-cheat, using something like [Anti-Cheat Toggler](https://www.nexusmods.com/eldenring/mods/90).
2. Install [EldenModLoader](https://www.nexusmods.com/eldenring/mods/117).
3. [Download](https://github.com/Logersnamed/EldenRing-NoCompass-Mod/releases) and extract the contents of **NoCompass.zip** into:  
   `...\steamapps\common\ELDEN RING\Game\mods`
4. Launch the game.
